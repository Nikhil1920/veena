languages.

## Ground rules

- **One repo, many toolchains.** Rust crates share the root Cargo workspace
  (run `cargo fmt` / `cargo clippy` from the repository root). Node apps keep
  their own lockfiles (`bun` for desktop, `pnpm` for web) — install and run
  inside the app directory.
- **Format before committing.** Desktop: `bun run format && bun run lint`.
  Web: `pnpm format`. Rust: `cargo fmt --all`.
- **Never commit** model binaries, built native libraries (`.so` /
  `.xcframework`), generated Xcode projects, signing keys, or the `.tauri/`
  key files — the root `.gitignore` encodes this; don't work around it.
- **Generated files:** `apps/desktop/src/bindings.ts` is regenerated by
  tauri-specta on debug runs — never hand-edit. `apps/ios/Veena.xcodeproj` is
  generated by XcodeGen from `project.yml`.
- **Engine changes** affect desktop, iOS, and Android at once: keep the C ABI
  in `crates/rust-backend/include/rust_backend.h` in sync with the Rust side
  and the app-side bridging headers.

## Pull requests

CI builds the desktop app for macOS, Linux, and Windows on PRs touching
`apps/desktop` or `crates/rust-backend`. Keep PRs scoped to one app or the
engine when possible.
